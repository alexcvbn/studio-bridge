# 회의 공간 (features/meeting)

협업 보드와 따로 있는 실시간 회의 화면. 협업 보드 위쪽의 **회의 공간** 버튼이나 주소 끝 `#meeting`으로 들어간다.
디자인은 10/23 UI 컨셉 그림과 피그마의 회의 기능(참여자·커서·따라가기·발표)을 따랐다.

## 할 수 있는 것
- **참여자**: 위쪽 동그라미와 "N명 참여 중". 내 동그라미를 누르면 이름을 바꾼다(처음 들어오면 이름을 묻는다. 로그인 계정이 아니라 이 브라우저에만 저장).
- **실시간 커서**: 다른 사람 커서가 이름표와 함께 보인다. 다른 사람이 고른 카드 위에는 그 사람 이름표가 붙는다.
- **따라가기**: 다른 사람 동그라미를 누르면 그 사람이 보는 곳을 따라간다. 내가 화면을 직접 움직이면 멈춘다.
- **발표**: 발표를 켜면 모두의 화면이 내 화면을 따라온다. 보는 사람은 "그만 보기"로 빠질 수 있다.
- **캔버스 카드**
  - 기능 카드: 한 줄 설명, 상태(논의 중 / 합의됨 / 보류, 눌러서 바꿈), 변경점(항목 이전 → 제안), 협의점 체크리스트, 연결된 구현(서버의 기능–자료 연결을 그대로 보여 줌), 상세·결정(협업 보드의 상세 보기로 이동)
  - 코드 카드, 메모, 의견(쓴 사람·시간), 이미지(올리기 또는 붙여넣기, 가로세로 900px JPEG로 줄여 저장)
  - 선 잇기: 카드 옆 동그라미를 끌거나, 선 잇기 도구(L)로 두 카드를 차례로 누른다
  - 지우기: 고른 뒤 휴지통 또는 Delete
- **기능 트리**(오른쪽): 기능 아래에 연결된 코드가 보이고, 누르면 카드로 올라간다. 새 기능도 여기서 만든다.
- **팀 채팅**(아래): 보드와 같이 저장돼서 나중에 들어와도 대화가 남는다(최근 500개).
- 단축키: V 선택, H 손, N 메모, C 의견, L 선 잇기, Esc 취소

## 데이터
- 카드·선·채팅은 협업 보드와 같은 동기화 문서(`studio-bridge/main`)의 `meeting.items`, `meeting.removedItems`, `meeting.edges`, `meeting.removedEdges`, `meeting.chat`에 저장된다. 협업 보드의 `cards`·`connections`와 섞이지 않는다.
- 참여자·커서·보는 위치·발표는 Yjs awareness(저장 안 됨)로 주고받는다.
- 서버(API)는 바꾸지 않았다. 기능·자료 목록과 기능–자료 연결은 기존 API를 읽기만 한다(새 기능 만들기 제외).

## 한계
- 같은 카드의 같은 칸을 두 사람이 동시에 고치면 나중에 저장한 쪽이 남는다(칸을 나갈 때 저장).
- 이미지는 동기화 문서에 들어가므로 아주 많이 올리면 보드가 무거워진다. 나중에 서버 업로드로 바꿀 수 있다.
- 음성·화면 공유는 없다.

# 협업 보드 사용 안내 (11회차 #42, B)

기능과 코드 자료를 카드로 올려 팀이 같은 화면을 보며 배치하고, 선으로 잇고, 공동 메모를 쓰는 화면입니다.
이 문서의 버튼 이름은 화면에 실제로 쓰인 이름입니다. 개발자용 설명은 같은 폴더의 `README.md`에 있습니다.

## 0. 시작하기 전에
서버 3개가 켜져 있어야 합니다. 순서와 명령은 `README.md`의 "실행" 또는 두 PC가 같이 쓸 때는 `server/README.md`의 "두 컴퓨터 공유 실행"을 따릅니다.
- 켜진 뒤 `http://localhost:5173`(다른 PC는 서버 PC 주소)을 엽니다.
- 오른쪽 위 **설정** 버튼(동그라미 아이콘)에 `설정 · 모두 연결됨`이 보이면 정상입니다.

## 1. 카드 올리기
1. 화면 아래 가운데 도구줄에서 **카드 추가**를 누릅니다.
2. 목록에서 올릴 항목의 `… 카드 추가` 버튼을 누릅니다. 위쪽 `기능·자료 검색` 칸으로 찾을 수 있습니다. (왼쪽 `카드 라이브러리`에서 `새 기능`으로 기능을 만들거나, Studio에서 보낸 코드가 `받은 자료함`에 있어야 목록에 나옵니다.)
3. 보드에 카드가 생깁니다. 같은 항목을 다시 추가하면 같은 대상을 가리키는 **새 카드**가 하나 더 생깁니다. (중복 방지는 없습니다.)

카드에는 종류(`기능` / `코드 자료`), 제목이 나옵니다. 기능 카드에는 상태·담당자·현재 결정·연결된 자료 수가 함께 나옵니다.

## 2. 카드 다루기
카드를 한 번 누르면 선택되고, 오른쪽 `상세 보기`에 그 기능·자료가 열립니다. 선택하면 카드 위쪽에 도구가 나옵니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 옮기기 | 카드를 끌어서 놓습니다. 다른 사람 화면에서도 같은 자리로 움직입니다. |
| 크기 바꾸기 | 선택한 카드의 테두리 손잡이를 끕니다. |
| 색 바꾸기 | 도구의 색 동그라미를 고릅니다. `기본색`으로 되돌릴 수 있습니다. |
| 상세 열기 | 카드를 누르거나 도구의 `상세 열기`를 누릅니다. |
| 카드 잇기 | 도구의 `선 잇기`를 누르고 이을 카드를 누릅니다. (카드 옆 동그라미를 끌어도 됩니다.) 취소는 빈 곳 클릭 또는 `Esc`. |
| 보드에서 지우기 | 도구의 휴지통(`보드에서 카드 제거`)을 누릅니다. |

- **카드를 지워도 서버의 기능·자료·결정은 그대로입니다.** 보드에서만 사라집니다. 지운 카드에 붙은 선도 같이 지워집니다.
- 선을 누르면 위쪽에 관계 종류(1:1·1:N·N:M), `관계 이름`, `방향 바꾸기`, `연결 지우기`가 나옵니다. 선이 점선이면 서버에 저장된 기능–자료 연결이고, 이 선은 보드에서 고르거나 지울 수 없습니다.
- 보드를 옮기려면 도구줄의 `손 도구`로 바꾸고, 다시 `선택`으로 돌아옵니다. `축소`·`확대`·`전체 카드 맞춤`은 오른쪽 아래에 있습니다.
- 카드가 겹치면 끌어서 떼어 놓습니다. (새 카드는 격자에 놓이지만 내용이 길면 서로 겹칠 수 있습니다.)

## 3. 공동 메모
도구줄의 `공동 메모 열기`(메모지 아이콘)를 눌러 쓰고, 닫을 때는 `공동 메모 닫기`입니다.
- 다른 사람이 동시에 써도 서로의 글이 사라지지 않습니다.
- 메모와 카드는 같은 서버에 저장되어 새로고침하거나 서버를 껐다 켜도 남습니다.

## 4. 연결이 끊기거나 오류가 날 때
화면 위 **설정**을 열면 `서버`와 `보드 동기화` 상태가 따로 나옵니다.

| 화면 문구 | 뜻 | 할 일 |
|---|---|---|
| `설정 · 모두 연결됨` | 정상 | 없음 |
| `동기화 서버에 연결할 수 없음 (서버가 꺼졌거나 주소가 다름)` | 동기화 서버가 꺼졌거나 주소가 다릅니다 | 동기화 서버가 켜져 있는지, 주소가 맞는지 확인합니다. 설정의 `다시 확인`을 누릅니다. |
| `접속 거절: 팀 키가 필요합니다` / `팀 키가 맞지 않습니다` | 공유 모드인데 키가 없거나 틀립니다 | 설정의 `팀 키`에 키를 넣고 `저장하고 다시 연결`을 누릅니다. 키는 서버를 띄운 사람에게 따로 받습니다. |
| `접속 거절: 이 PC에서만 연결할 수 있는 서버입니다` | 로컬 모드 서버에 다른 PC가 붙었습니다 | 서버 PC에서 공유 모드로 다시 띄웁니다. |
| 카드 제목 대신 `찾을 수 없음` | 그 카드가 가리키는 기능·자료가 서버에 없습니다 | 방금 만든 대상이면 몇 초 안에 제목이 나타납니다. 계속 남으면 카드를 지웁니다. |
| 카드 제목 대신 `확인 실패` | 기능·자료 목록을 읽지 못했습니다 | 왼쪽 `작업공간 새로고침` 또는 `다시 시도`를 누릅니다. |

- 끊긴 동안 쓴 메모와 카드 변경은 **그 화면에 남아** 있다가 다시 연결되면 합쳐집니다. 끊긴 채 화면을 닫으면 사라질 수 있습니다.
- 접속이 **거절된** 동안 쓴 내용은 서버에 저장되지 않고 다른 사람에게도 보이지 않습니다.
- 서버를 끄고 켜도 보드는 돌아옵니다. 보드를 연 브라우저는 서버가 돌아오면 자동으로 다시 연결합니다.

## 5. 알려진 한계 (지원하지 않는 것)
- 보드는 하나(`studio-bridge/main`)뿐입니다. 화면에서 다른 보드로 바꿀 수 없습니다.
- 실행 취소(되돌리기), 카드 이름 바꾸기, 채팅, 다른 사람 커서 표시는 없습니다.
- 완전한 오프라인 편집은 지원하지 않습니다. 연결이 끊긴 채 오래 쓰지 마세요.
- 같은 카드를 두 사람이 동시에 옮기면 두 화면은 같은 위치로 맞춰지지만, 어느 쪽 위치가 남는지는 정해져 있지 않습니다.
- 같은 순간에 두 사람이 카드를 추가하면 둘 다 생기고 겹칠 수 있습니다. 데이터는 잃지 않습니다.
- 카드를 지운 직후 다른 사람이 늦게 옮긴 카드는 다시 나타나지 않습니다. 단, 브라우저가 하나도 열려 있지 않을 때 들어온 것은 다음 접속 때 정리됩니다.

## 6. 저장과 백업
- 보드(카드·연결선·메모)는 동기화 서버의 `sync/data/`에, 자료·기능·결정은 `server/studio_bridge.db`에 저장됩니다. **둘은 따로 저장**되므로 같은 시점에 함께 백업해야 합니다.
- 백업·복원 순서는 `server/BACKUP.md`를 따릅니다. 서버 두 개를 끈 뒤 백업하고, 새 폴더에 복원해 `verify`로 확인합니다. 실제 데이터로 되돌릴 때는 보드를 연 브라우저 탭을 모두 닫습니다.
- Windows에서는 `backup_restore.py`가 보드의 한글(메모 등)을 읽다 실패하던 문제를 고쳤습니다(`encoding="utf-8"`). 이전 버전을 쓰고 있다면 최신 `main`을 받으세요.

## 7. 처음 쓰는 사람이 따라 하는 확인표
다른 사람이 위 안내만 보고 아래를 한 번씩 해 보고, 막힌 문구를 이슈에 적습니다.

| # | 조작 | 기대 결과 |
|---|---|---|
| 1 | `카드 추가` → 기능 하나 선택 | 보드에 기능 카드가 생기고 `카드 N개`가 하나 늘어난다 |
| 2 | 카드를 끌어 옮긴다 | 다른 사람(다른 PC) 화면에서도 같은 자리로 움직인다 |
| 3 | 자료 카드를 하나 더 올리고 `선 잇기`로 두 카드를 잇는다 | 선이 생기고 `연결 1개`가 된다 |
| 4 | `공동 메모 열기`에서 글을 쓴다 | 다른 사람 화면의 메모에도 같은 글이 나타난다 |
| 5 | 카드를 선택하고 `보드에서 카드 제거` | 카드와 붙은 선이 사라지고, 왼쪽 라이브러리의 기능·자료는 그대로다 |
| 6 | 동기화 서버를 껐다 켠다 | `동기화 서버에 연결할 수 없음`이 나왔다가 자동으로 `모두 연결됨`이 되고 카드·메모가 그대로다 |
| 7 | 모든 브라우저를 닫고 서버를 재시작한 뒤 다시 연다 | 지운 카드는 없고 나머지 카드·선·메모는 그대로다 |
| 8 | (공유 모드) 틀린 팀 키를 저장한다 | `접속 거절: 팀 키가 맞지 않습니다`가 나온다 |
